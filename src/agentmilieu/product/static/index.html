01 / The pipeline

Context is an input.
Trust is a process.

Small context windows leave little room for noise. Every source passes through six stages before it can reach your model.

01 — INGEST

Keep the source.

Bring public web links, PDFs, Markdown and notes together. Preserve provenance as documents become chunks.

02 — SANITISE

Separate signal from risk.

Redact PII and secrets. Quarantine suspected prompt injections with a report, rather than silently dropping them.

03 — BUDGET

Know what fits.

Use the GGUF model profile and device RAM to calculate a conservative context and KV-cache budget.

04 — COMPOSE

Make every token count.

Stuff, compress or retrieve with BM25. Keep the citations attached and the pack within budget.

05 — AUDIT

Leave a paper trail.

Inspect the scorecard and safety reports. Export local FastMCP tools with your approved pack.

06 — REVIEW

A human gets the last word.

Approve locally or through Notion. Export rechecks approval and the content hash before releasing a pack.

APPROVED + HASH MATCH → EXPORTPENDING / REJECTED / CHANGED → REFUSED
02 / Capabilities

Less guesswork.
More control over the input.

⌘

Model & device-aware budgets

Read exact GGUF headers from Hugging Face without downloading weights. Account for layers, KV heads, quantisation and available memory.

⊘

Local heuristic safety

Rules process private data and suspicious instructions before composition. Quarantine reports make the decisions inspectable.

↳

Citations that stay attached

Source provenance survives stuffing, compression and BM25 retrieval, so the resulting context remains traceable.

{ }

Narrow FastMCP tools

Generate standalone, local tools for each pack. Give an agent the capability it needs without an unnecessarily broad interface.

✓

Hash-checked review gates

Drafts start as Pending in Notion or a local registry. Approval is checked again on every export, along with the content hash.

>_

Flexible compression providers

Choose extractive compression, a managed model, or your own OpenAI-compatible or Anthropic-compatible API key.
